# 합성 작성 예시: 메모 정리용 브라우저 앱

이 문서는 양식 설명을 위해 만든 합성 예시다. 실제 행사·사용자 결정·심사 기준·제품·URL·수상 기록이 아니며 실제 실행하지 않았다. 복사한 문구나 가상 경로를 실제 evidence로 사용하지 않는다. 시간·수치·승인·실행 결과를 지어내지 않는다.

## 1. 제품 명세 예시

- 사용자와 상황: 회의 뒤 자기 메모에서 후속 작업을 정리하려는 참가자라는 가설.
- 입력: 개인정보를 제거한 짧은 메모 텍스트. 이 예시에서는 AI나 외부 API를 쓰지 않는다.
- 행동: 사용자가 한 줄씩 작업으로 옮기고 완료 여부를 직접 표시한다.
- 결과: 정리한 목록을 브라우저에서 텍스트로 내려받는다.
- 지원: 입력·직접 편집·내려받기. 제외: 자동 업무 추출·로그인·팀 공유·기한 추정.
- 고정/가변: 입력란과 목록 조작은 고정, 항목 내용은 사용자 입력에 따라 달라진다.
- 책임: 사람은 항목을 정한다. 코드는 목록과 파일을 처리한다. AI 책임은 없다.
- 미결정: 새로고침 이후 보존 필요 여부는 사용자 결정 대기. 현재 저장 기능이 있다고 주장하지 않는다.

이는 명세 형식 예시일 뿐 설계 승인·criteria 수립·제품 준비 완료가 아니다.

## 2. 현장 실행표 예시

실제 시각은 공식 제작 시간 확인 전이므로 미정이다. 아래는 순서와 분기만 보여준다.

### 첫 E2E

- 작업: 메모 한 항목 입력 → 목록 편집 → 텍스트 내려받기.
- 담당: 사용자 결정 대기.
- 확인 시점: 공식 시작 후 첫 구현 구간. 구체 예산은 공식 일정 확인 후 결정.
- 완료 증거: 구현 전 허용된 criteria에서 고정한 입력 보존·순서·파일 내용 기준과 실제 파일을 비교한 기록. 현재 실행 evidence는 없음.
- 실제 상태: 미구현·미실행 / UNVERIFIED.
- 미달 시: 범위를 늘리지 않고 깨진 입력→결과 경로를 복구한다. 핵심 파일 내용 오류는 장식이나 인증 추가로 우회하지 않는다.

### 조기 배포 또는 실행환경 확인

- 작업: 실제 발표 기기에서 앱을 열고 동일 경로를 실행한다.
- 확인 시점: 첫 E2E 뒤, 추가 기능 전에.
- 완료 증거: 깨끗한 환경의 실행 방법과 파일 내려받기 확인 기록. 현재 없음.
- 미달 시: 허용된 로컬 실행을 검토하되, 공개 URL이 필수라면 제출 조건 미충족을 명시한다.

### 검증과 발표 준비

- 작업: 빈 입력·편집·내려받기를 독립 기준으로 확인하고 실제 화면 cue와 백업을 준비한다.
- 확인 시점: 기능 동결 전후의 실제 예산은 미정.
- 완료 증거: 실행 기록, 검수된 자료, 실제 발화·조작 리허설. 현재 모두 미실시.
- 미달 시: 미검증 주장을 제외한다. 깨진 핵심 가치를 성공으로 설명하지 않는다.

sponsor는 이 가상 제품의 채택 대상이 없어 최초 호출 안내를 생략한다. 실제 행사 sponsor 요건이 없다는 뜻은 아니다.

## 3. 공통 사실표 예시

- 현재 build / 제품 위치: 없음. 예시일 뿐이다.
- claim ID: C1
- 주장: 사용자가 직접 정리한 목록을 텍스트 파일로 내려받는다.
- 출처: 위 가상 명세만 있음. 실제 실행 evidence 없음.
- 검증 경로 / 판정: 미실행 / UNVERIFIED.
- 사용 가능 범위: 계획 설명만 가능. 현재 구현된 기능·성과로는 사용 불가.
- 제외할 주장: 자동 추출, 팀 공유, 시간 절감 수치, 저장 안정성.
- 변경 영향: 보존 방식을 결정하면 명세·설계·독립 criteria·관련 자료를 재검토한다. 기존 결과를 새 기준으로 소급 PASS 처리하지 않는다.

## 4. 심사 기준별 증거 예시

- 공식 기준: 미확인. 임의 점수·가중치를 만들지 않는다.
- 공식 출처: 없음.
- 준비할 장면: 메모 입력에서 내려받은 파일 확인까지 한 경로.
- 실제 evidence: 없음 / UNVERIFIED.
- 자료 인용: 계획만 설명 가능. 혁신성 점수나 제품 PASS를 주장하지 않는다.

실제 행사에서는 원문 기준을 확인한 뒤 장면과 실행 evidence를 연결한다. 이 예시 자체를 공식 기준이나 증거로 쓰지 않는다.
