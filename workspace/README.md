# Workspace

해커톤별 작업 기록과 산출물을 보관한다.

각 행사는 별도 폴더를 쓴다.

```
workspace/<event-slug>/
```

예:

```
workspace/2026-example-hackathon-seoul/
```

이 폴더는 Git에 커밋할 수 있는 상태로 유지한다. 종료된 행사 폴더는 기록으로 두고 새 구조로 옮기지 않는다.

저장해도 되는 것:
- hackathon 설정
- ideation 결과
- design 방향
- preparation 기록
- adaptation 기록
- demo contract
- preflight 기록 (pre-event, final)
- deck / pitch / submission 산출물
- retro

저장하지 않는 것:
- API key
- access token
- password
- 개인 정보
- 공개하면 안 되는 sponsor credential
