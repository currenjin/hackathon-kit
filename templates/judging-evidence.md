# 심사 기준별 증거 양식

[인계 규칙](../references/delivery-handoffs.md)을 따른다. 기존 slide map이나 제출 준비 문서에 넣을 수 있다. 별도 파일을 필수로 만들지 않는다.

## 공식 기준

- 원문과 출처 / 확인 시각: 미확인
- 공식 가중치 (없으면 미공개, 추정 금지): 미확인
- 적용 트랙과 참가 요건: 미확인

기준별로 아래를 반복한다.

- 공식 기준 원문:
- 보여줄 사용자 행동과 결과:
- deck 장면 / pitch cue / submission 주장과 버전:
- 실제 실행 evidence / scenario / build / 실행 시각:
- 검증 경로 (local/mock/실제 provider/미실행):
- 한계 / 충족 여부 미확인 / 추가 확인:

심사 기준이 미확인이면 임의 기준이나 심사 점수를 만들지 않는다. 공식 행사 목표·참가 요건은 별도 절에 적는다. 미실행은 근거 대기이지 충족 증거가 아니다. 이 기록은 제품 PASS, 독립 demo contract, 출품 자격 또는 점수 보장을 대신하지 않는다.

## 제작 이력과 인용 점검

- 상속한 starter / 라이브러리 / prompt / 데이터와 출처·라이선스:
- 공식 제작 시간 안에 새로 만든 부분과 근거:
- 자격 판단 원문 / 재사용 허용 여부 / 미확인 사항:
- 실제 확인한 자료 버전 / 링크 접근 / 검수 시각:

실제 evidence 없는 성과 주장은 제외하거나 한계로 쓴다. 예제 실행과 제품 가치, 승인 결정과 실제 실행을 혼동하지 않는다.
