# 공통 사실표 양식

[인계 규칙](../references/delivery-handoffs.md)을 먼저 읽는다. workspace 안의 기존 기록에 필요한 절만 사용한다. 빈 양식·파일 존재는 완료 증거가 아니다. 이 파일은 사실의 색인이며 공식 원문·독립 contract·실행 evidence를 대체하지 않는다.

## 현재 기준

- 현재 build / 제품 위치 / 실제 확인 시각: 미확인
- 사실표 버전 또는 검수 시각: 미확인
- 제품명과 한 줄 설명의 원본: 미확인
- 사용자와 상황 / 입력 → 행동 → 결과: 미정
- 지원 범위 / 제외 범위: 미정
- 실제 사용 기술과 sponsor: 미검증 (채택 결정과 사용 증거를 구분)
- 공개 링크 원본과 접근 확인: 미확인

## claim 색인

각 주장마다 반복한다. 숫자·성능·수상·차별점은 출처 없는 상태로 채우지 않는다.

- claim ID와 정확한 주장:
- 출처 (공식 원문 또는 독립 contract와 실제 실행 evidence):
- 현재 build / 실행 시각 / scenario:
- 검증 경로 (local/mock/실제 provider/미실행):
- 판정과 사용 가능 범위 (검증된 범위만):
- 미검증 부분과 제외/한계:
- 인용한 deck / pitch / guide / submission의 경로와 버전:

## 변경 영향과 일관성 검수

- 이전값 → 확인된 새 값 / 변경 이유 / 근거:
- 영향받는 자료의 경로와 버전 / 갱신·재검수 대기:
- 실제 대조한 자료와 언어 / 검수자 / 시각 / 결과:
- 불일치 주장과 해결·제외 여부:

현재 자료 변경과 과거 제출 이력은 분리한다. 이미 제출한 문구·접수 근거·당시 버전은 보존한다. 번역과 요약으로 미검증 주장을 성과로 바꾸지 않는다.
